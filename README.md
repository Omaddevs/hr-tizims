# IAU HR — Universitet HR avtomatlashtirish platformasi

React + Vite + TypeScript + Tailwind. 1 HR xodimi + workflow + employee self-service + AI Copilot modeli.

## Ishga tushirish

```bash
npm install
npm run dev
```

Brauzer: http://localhost:2004

> Dev server qat'iy 2004-portda ochiladi.
